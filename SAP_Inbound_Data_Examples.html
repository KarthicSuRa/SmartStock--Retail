Example 2 — Open Purchase Orders (In-Transit Stock)

APIPURCHASEORDER_PROCESSSRV → A_PurchaseOrderItem

Scenario: SmartStock checks which SKUs already have stock on the way from vendors, so it does not generate duplicate replenishment orders. SAP OData Request: 
GET /sap/opu/odata/sap/API_PURCHASEORDER_PROCESS_SRV/A_PurchaseOrderItem
    ?$format=json
    &$filter=OrderQuantity gt ReceivedQuantity and MandatoryPrcmtDocIsDeleted eq false
    &sap-client=100
Authorization: Basic czRoYW5hX3VzZXI6cGFzc3dvcmQ=
Accept: application/json
Sync frequency: 15-minute delta sweep. Only lines where OrderQuantity > ReceivedQuantity (still open) and MandatoryPrcmtDocIsDeleted = false (not cancelled) are returned.

What SmartStock Does With It:

During an active promotion, the daily velocity used for replenishment calculations is overridden:


Normal Daily Velocity of MAT-FMCG-002 = (812 units / 30 days) = 27 units/day

During "Summer Cola Weekend" (uplift_factor = 2.5):
  Promotional Velocity = 27 × 2.5 = 67.5 units/day

Run-Out Horizon = 812 ÷ 67.5 = 12 days  →  REPLENISHMENT_NEEDED alert fires early
  • SmartStock alerts the store manager to pre-order extra stock before the promotion starts
  • The discount_percentage is also surfaced in the replenishment UI so managers can communicate pricing to vendors
  • Once the promotion's end_date passes, the velocity reverts automatically to the normal POS-calculated value

Full End-to-End Example — How All 5 Feed Into One Decision

Scenario: It is Monday morning. MAT-FMCG-001 (Rotterdam Fresh Whole Milk 1L) at Plant 1001 needs a replenishment decision.
Data SourceValue LoadedImpact on Decision
Baseline (Ex. 3)sapbaselineqty = 340Starting stock for the week
POS Events (intraday)poslivedeductions = 180 sold since last synccurrentcalculatedstock = 340 − 180 = 160
Info Record (Ex. 1)vendorleaddays = 2, minbm_moq = 50, netpr_price = 1.25Must order by today for 2-day delivery; order in multiples of 50
Open PO (Ex. 2)openinboundqty = 120 already on the waynet_deficit = (target 300) − 160 − 120 = 20 → still need 20 more (round up to MOQ of 50)
Promotion (Ex. 5)Dairy Fest starts in 9 days, uplift_factor = 1.8Velocity spikes from 11/day to 19.8/day → stock will run out in 8 days → order extra 60 units for promo buffer
Plant Master (Ex. 4)Plant 1001 = Rotterdam Centraal Outlet, 7001 = Moerdijk DCChecks if Moerdijk DC has surplus → surfaces lateral STO option to save cost
Final SmartStock Recommendation:
Order 110 units of MAT-FMCG-001 from V-1001 (Rotterdam Dairy Co.) at €1.25/unit = €137.50 — covering current net deficit + promotional uplift buffer. Alternatively, transfer 60 units from Moerdijk DC (Plant 7001) via STO at zero cost.
