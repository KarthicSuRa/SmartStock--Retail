# SmartStock Inventory Control — Product Package v1.0

## 1. Core Pilot Capability Matrix

SmartStock v1.0 is packaged as **SmartStock Inventory Control** — a focused, high-value enterprise solution.

### Included in V1.0 (Core Pilot Offering)
- **Real-Time Inventory Digital Twin**: Sub-second operational projections distinguishing on-hand, sellable, reserved, and in-transit quantities.
- **Explainable Inventory Timeline**: Complete chronological event audit trail answering *"Why does SmartStock believe inventory is X?"*
- **Continuous ERP Reconciliation**: Automated nightly and intraday reconciliation against SAP S/4HANA OData baselines with explained vs unexplained variance isolation.
- **Rule-Based Confidence Scoring**: Calibrated 0–100 certainty scores with factor breakdown.
- **Exception Inbox**: Actionable, prioritized workflow center with revenue-at-risk scoring.
- **Smart Cycle Counts & Observations**: Two-stage observation and approval workflow preventing accidental adjustments.
- **Multi-Factor STO Optimization**: Internal-transfer-first replenishment recommending nearest surplus fulfillment.
- **Durable Enterprise Outbox**: Reliable, idempotent batch posting to SAP with `OUTCOME_UNKNOWN` safety guards.
- **Integration Control Tower**: Feed latency, queue depth, and silent store detection.
- **Mobile Floor Staff PWA**: Offline-first task execution (counts, markdowns, restocks).

### Explicitly Excluded from V1.0 (Deferred to Future Add-on Modules)
- Generative AI / Large Language Models
- Shelf Vision / Computer Vision Edge Hardware
- 3-Way Invoice Matching / Vendor Billing
- Multi-Region Active-Active Cloud Topologies
- Direct Vendor Self-Service Portal
